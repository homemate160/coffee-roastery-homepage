# 커피 로스터리 홈페이지 (시안)

스몰 배치 커피 로스터리 홈페이지 시안입니다. 브랜드 이름 "느린 불씨"는 가칭이며, 문구와 원두 정보, 사업자 정보는 임시입니다.

공개 주소 : https://coffee-roastery-homepage.vercel.app/ (Vercel, GitHub main에 올리면 자동 배포)

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 대표 페이지 (애플풍) |
| `drafts/index_v1_three_styles.html` | 첫 시안 : 미니멀, 따뜻한 공방, 묵직한 다크 3종 전환 |
| `drafts/index_v3_editorial.html` | 잡지형 에디토리얼 시안 |

## 문의 양식

맨 아래 문의 양식으로 보낸 내용은 구글 시트 "홈페이지 문의"의 "문의" 탭에 쌓이고, 사장님 Gmail로 알림이 갑니다.

- 구글 쪽 코드 : `google_sheet/문의_시트_연동.gs` (실제 작동본은 구글 Apps Script "홈페이지 문의 접수" 프로젝트에 있음)
- 설정 방법 : `google_sheet/설정_방법.md`
- 스팸 방지 : 숨은 함정 칸, 3초 안에 보내면 무시, 같은 내용 반복 무시, 한 사람 6시간 5건, 전체 시간당 40건, 알림 메일 시간당 5통
- 구글 쪽 코드를 고치면 Apps Script에서 "배포 관리 > 새 버전"으로 다시 배포해야 반영됩니다.
