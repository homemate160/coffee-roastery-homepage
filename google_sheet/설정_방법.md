# 홈페이지 문의를 구글 시트로 받는 설정 방법

손님이 홈페이지에서 보내기를 누르면,

1. 구글 시트의 "문의" 탭에 한 줄이 추가되고
2. 사장님 메일로 알림이 갑니다.

외부 업체를 거치지 않고 사장님 구글 계정 안에서만 처리됩니다. 비용은 없습니다.

준비물 : 구글 계정, 같은 폴더의 `문의_시트_연동.gs` 파일

걸리는 시간 : 10분 정도

## 1단계 : 시트 만들기

1. 인터넷 주소창에 `sheets.new` 를 치면 빈 구글 시트가 열립니다.
2. 왼쪽 위 "제목 없는 스프레드시트"를 눌러 이름을 `홈페이지 문의` 로 바꿉니다.

## 2단계 : 코드 붙여 넣기

1. 시트 위쪽 메뉴에서 **확장 프로그램 > Apps Script** 를 누릅니다. 새 창이 열립니다.
2. 이미 적혀 있는 `function myFunction() { }` 을 전부 지웁니다.
3. `문의_시트_연동.gs` 파일을 메모장으로 열어 내용 전체를 복사(Ctrl+A, Ctrl+C)해서 붙여 넣습니다.
4. Ctrl+S 를 눌러 저장합니다.

## 3단계 : 처음 한 번 실행해서 권한 주기

1. 편집기 위쪽, 실행 버튼 옆의 선택 칸에서 **처음_설정** 을 고릅니다.
2. **실행** 을 누릅니다.
3. "승인 필요" 창이 뜨면 **권한 검토** > 본인 계정 선택을 누릅니다.
4. "Google에서 확인하지 않은 앱" 이라는 경고가 나옵니다. 사장님이 직접 만든 코드라서 나오는 정상 경고입니다.
   **고급** > **(프로젝트 이름)(으)로 이동(안전하지 않음)** > **허용** 을 누릅니다.
5. 확인할 것 :
   - 메일함에 "[홈페이지 문의] 설정 시험 님" 메일이 왔는지
   - 시트에 "문의" 탭이 새로 생겼는지

## 4단계 : 웹 앱으로 배포하기

1. 편집기 오른쪽 위 **배포 > 새 배포** 를 누릅니다.
2. "유형 선택" 옆 톱니바퀴를 눌러 **웹 앱** 을 고릅니다.
3. 아래처럼 맞춥니다.
   - 설명 : `홈페이지 문의`
   - 다음 사용자 인증 정보로 실행 : **나**
   - 액세스 권한이 있는 사용자 : **모든 사용자**
4. **배포** 를 누릅니다.
5. 나오는 **웹 앱 URL** 을 복사합니다. `https://script.google.com/macros/s/` 로 시작해서 `/exec` 로 끝나는 주소입니다.
6. 이 주소를 Claude에게 보내 주세요. 홈페이지에 연결하고 시험 문의를 보내 보겠습니다.

"모든 사용자" 로 해야 홈페이지 방문자가 로그인 없이 문의를 보낼 수 있습니다. 방문자는 이 주소로 문의를 "보낼" 수만 있고, 시트를 보거나 고칠 수는 없습니다.

## 알아 두실 점

- **코드를 고쳤을 때** : 저장만 하면 홈페이지에 반영되지 않습니다. **배포 > 배포 관리 > 연필 아이콘 > 버전 : 새 버전 > 배포** 를 해야 합니다. 이렇게 하면 주소는 그대로 유지됩니다.
- **알림 받을 메일을 바꾸고 싶을 때** : 코드 맨 위 `NOTIFY_EMAIL = '';` 의 따옴표 사이에 메일 주소를 넣고, 위 방법대로 새 버전으로 배포합니다.
- **메일 한도** : 일반 구글 계정은 이 방식으로 보낼 수 있는 메일 수에 하루 한도가 있습니다(공식 문서 기준 하루 100통 안팎, 바뀔 수 있음). 한도를 넘어도 시트에는 계속 쌓입니다.
- **처리 상태, 메모 칸** : 답장했으면 "처리 상태" 를 `답장 완료` 처럼 직접 바꿔 쓰시면 됩니다.
- **보관 기간** : 홈페이지 동의 문구에 "답변 완료 후 1년 뒤 삭제" 라고 적어 두었습니다. 기간이 지난 줄은 직접 지워 주세요. 기간을 바꾸고 싶으면 알려 주세요.
- **시트 공유 주의** : 이 시트에는 손님 개인정보가 쌓입니다. "링크가 있는 모든 사용자" 로 공유하지 마세요.
